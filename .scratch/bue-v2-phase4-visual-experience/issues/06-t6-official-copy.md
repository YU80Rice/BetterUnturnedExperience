## Question

1. **功能描述**：BII / LIT / LIR / LHT / BUE Network / v1compat / ClientUi 各自一句话描述是否本阶段必填？谁是事实源（注册面字段 vs 面板硬编码表）？跟随 T3 的裁决，本票只填内容。
2. **LIT 设置文案**：模式、方向两条的显示名与描述正文（T5 定键，本票定字）。
3. **其它官方设置**：现有 SettingId 当显示名的条目，本阶段是全部改成中文显示名+描述，还是只改玩家会点的（LIT + 各功能 enabled 退役后剩下的）？
4. **网络模块详情**：接管状态 /「让我改回独立 LMN」是否保持现状文案，还是只保证不进本阶段重做？
5. **NoOpFixture**：生态样板是否必须带描述 + 至少一条 Choice，作为开发者对照？

输出：文案表（功能 → 描述；SettingId → 显示名/描述/档位名），供 /to-spec 原文引用。

## Answer

2026-09-11 用户 Q60–Q64 定音。本票交付=官方与 NoOp 的功能级一句话 + 仍可见设置的显示名/描述。三缝分开：chrome 对照表、设置描述、运行时状态投影。文案不得扩大功能能力，不得替代生命周期或设置权威。

### Q60 — 功能级一句话（chrome 对照表）

事实源=管理面板 ClientUi chrome 对照表，不进公开契约。管理面板自身不在目录，不写条目。无对照表的生态条目不画、不占位。

| 条目 | 一句话 |
|---|---|
| 更好的物品交互 | 在支持的格子里增强拖入，失败时回到原版操作。 |
| 背包整理 | 整理背包与装备栏物品；模式和方向在本页设置，背包标题栏点「整理」。 |
| 更好的换弹体验 | 换弹尽量留在原位；背包整理完成后自动压缩弹药。 |
| 更好的尸潮播报 | 由主机追踪尸潮，并在客户端显示播报。 |
| BUE 网络模块 | 为 BUE 功能模块提供多人通信通道；可停用，停用不等于卸载。 |
| BUE V1 兼容层 | 为仍使用数字频道的旧插件提供兼容接收，不提供新的注册入口。 |
| NoOpFixture | 生态接入样板，用于展示功能描述、Toggle 和 Choice 在面板中的呈现。 |

对照表不得替代功能状态、设置描述或 SDK。网络文案写「BUE 功能模块」，不缩成「仅官方」。背包整理覆盖 Hands/Backpack/Vest/Shirt/Pants，不写「服装栏」。

### Q61 — LIT 模式与方向

| SettingId | 显示名 | 描述 |
|---|---|---|
| `inventorytidy.mode` | 整理模式 | 同类：把相同物品聚在一起；空间：优先保留大块空位；大件：优先放置大件。对当前栏整理和全身整理都生效。 |
| `inventorytidy.direction` | 整理方向 | 降序：大件优先；升序：小件优先。与整理模式共同决定整理顺序。 |

档位字面量仍是 T5 的 `同类`/`空间`/`大件`、`降序`/`升序`。描述解释玩家可见效果，不承诺排序算法或 O-LIT-1。120 是显示截断，不是正文契约上限。中文档位本阶段同时是机器值与显示值，不称为跨语言稳定枚举。

### Q62 — 其余官方设置

只写玩家本阶段还看得到的设置。退役的 `enabled` / BII `Enabled`：不生成新 descriptor、不进草稿、不参与普通设置保存、不画空描述占位；旧值只走 T4 legacy alias。

| SettingId | 显示名 | 描述 |
|---|---|---|
| BII `AutoRotate` | 自动旋转 | 拖入时自动旋转物品以适配空位。 |

LIR / LHT / Network / v1compat 可以没有普通设置行；详情仍显示功能级一句话、功能状态、表现状态、功能级启停。没有普通设置行 ≠ 详情为空。

### Q63 — 网络接管文案

本阶段不重写「接管状态」「配置迁移」「让我改回独立 LMN」。保留现状绘制：不进对照表、不改交互、不进草稿、不参与启停保存。不代表这些句子已被重新验证为最终产品语言。`bue.network` 良性隔离看起来像故障，另开可视化票。

### Q64 — NoOp

保留 Toggle，另加 Choice（不把 probe-toggle 改成 Choice）：

| SettingId | 显示名 | 描述 | 档位 | 默认 |
|---|---|---|---|---|
| `noop.probe-toggle` | 探针开关 | 样板用的开关，证明生态 Toggle 能出现在面板。 | — | 开 |
| `noop.probe-choice` | 探针档位 | 样板用的循环切换，证明生态 Choice 能出现在面板。 | `甲` / `乙` | `甲` |

`noop.probe-choice` 必须非空 AllowedValues；改草稿；不是生命周期代理；`noop.probe-toggle` 不登记 legacy alias。NoOp 不替代 LIT 对 Choice 的官方先行消费。
