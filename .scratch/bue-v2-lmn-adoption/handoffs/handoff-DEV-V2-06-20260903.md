## 06 三接缝决策（本会话定稿；冻结锚点均已核实，交双轴审查时引本条）

1. **V1 注册入口落地机制 = Refresh 时反射镜像**：探针 true 时读 LMN `ModTransport.ServerHandlers/ClientHandlers` 静态字典，逐条 wrap 进 05 的 `LmnV1CompatRegistry`；`ulong` → 委托首参类型 `Activator.CreateInstance(paramType, ulong)`（免 Steamworks 编译期引用）。锚点：spec L75「BUE 接管 LMN 注册入口…兼容层兜底」。镜像失败（Type 解析 null/字段缺失/异常）→ 诊断 `BUE-V2NET-00x` + V1 帧走未知频道丢弃路径，绝不 crash。
2. **LMN2 帧 = Prefix 决策后反射委托 LMN 自身 router 作后端**：`TryHandleFromClient/FromServer` 返回 true → Prefix `return false`；返回 false（解析失败）→ `return true`；异常 → 诊断 + `return true`（降级交还 LMN Prefix 自愈）。"唯一 Hook"= BUE 是唯一 patch 决策点；LMN Prefix 永不被调（正常路径）。锚点：spec L84 双魔数短路 + T5 L83 象限完整；终局 = DEV-V2-08 吸收（08 票 L14「不再需要独立 LMN DLL」）。
3. **V1 兼容开关 = 独立 facet** `io.github.yu80rice.bue.network.v1compat`（descriptor `v1compat.enabled` Toggle 默认 true）；网络模块 facet = `io.github.yu80rice.bue.network`（仅 `network.enabled` Toggle 默认 true，票 L14「仅含启用/禁用开关」）。锚点：spec T4 L74「面板可关，与网络模块开关独立」——**票面未列 V1 兼容开关，spec 锚定归位**，交付报告须说明。
   + **前缀激活三元条件**：`networkEnabled && takeoverActive(探针) && LMN 帧`；**可逆钮 = 把 network.enabled 置 false → IsolateAndDetach（harmony.UnpatchSelf）→ LMN Prefix 恢复独立运行**（T5 L93 恢复语义，按钮语义与网络模块可关对齐 T5 待格审 4）。
