## Question

LMN 纳入后的 BUE 官方网络模块，归入"核心 / 可选 / 实验性"哪一级？

## 决策要点

1. 分级规则（CONTEXT.md L41-51）：核心和可选默认启用、实验性默认关闭；分级决定默认启用和稳定性承诺，不改变兼容/回退/隔离约束。
2. LMN 网络模块的定位：默认启用（CONTEXT.md L73-75「BUE 网络模块默认策略」已定默认启用）——但默认启用与"核心/可选"不冲突（核心、可选都默认启用）。
3. 定级考量：网络层是基础设施（偏核心）还是可替换组件（偏可选）？与官方功能"玩家可关闭"义务如何协调？
4. 故障隔离联动：核心级故障触发全局安全降级 vs 功能级故障只隔离该功能——网络模块定级直接影响这个边界。
