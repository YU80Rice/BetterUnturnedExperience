## Question

1. 显示方法和加点以及等级描述使用**游戏原版的技能显示模板**，不要自己造格式（开图 Q10 A：看起来像原版技能行，进度仍 LIR 自管，不占原版槽）；
2. 同一角色进不同地图，原版技能会重置，换弹技能现在不会——要把原版 skill 的升级/存档作用域复现到 LIR 上（开图 Q17：每份世界/存档一份等级，旧全局文件不再生效，每个世界从 0 起；花费仍 125/150）。

R3（原版技能页控件）与 R5（原版技能存档作用域）是事实输入。T1 须先授权重开「全局技能账」不变量。等级模型 0～2、不占原版槽、花原版经验、新档不送级、无三级——开图未推翻，本票默认沿用，若要改须显式写。

本票裁决产品语义，不在本票改 UI 代码：

1. **「原版技能显示模板」复刻到哪一层**：图标、名称、当前级/满级、花费、加点按钮、描述折行，哪些必须像、哪些可以没有？找不到可挂的原版 `SleekSkill` 时，是复刻其几何/控件组合，还是降级回设置页（现网表面 B）？

4. **旧账**：全局 dat 丢弃且每个世界从 0（开图推荐，用户同意）。要不要在第一次打开技能页时给一条说明？禁止静默把全局满级抄进每一份新世界。
5. **表面互斥**：现网「探测失败才挂设置页降级面」是否保留？原版模板接不上时玩家如何加点？

## Answer

2026-09-21 用户五项全部定音。被动压弹语义以被动压弹票为准，本票不重写 8 秒周期。跨表面共享裁决已钉的契约 / 不占原版槽 / 画面类 Headless / 升级扣经验主机必真跑，本票不重开。本票不改 UI 代码。玩家手册说明句归文案票。

冻结句：

> **换弹技能是 LIR 自有的 0～2 级玩家进度，不占原版技能槽、不写原版技能数组，但在视觉和交互上复刻原版技能行。等级按 `serverID × characterID × 地图名` 分家，旧全局账不迁移；战斗区复刻行优先，探测失败才降级到设置页，任何时刻只显示一个表面并共用同一主机权威。**

治本边界（用户原话级）：复刻原版的视觉和交互结构，不复用会写入原版 `Skill[][]` 的原版技能对象。

### Q1 — 复刻行，不复用 SleekSkill

- 必须有：技能名称、当前级/满级、描述、升级花费或 Full、整行可点击升级。经验不足时整行不可点。0/1/2 三格锁条显示当前进度。
- 不造职业小图标，不造条件加成数字，避免伪装成原版技能资产。
- 几何靠近原版全幅行高 80 / 步进 90，不再用现网 36 像素自造行。仍挂在 U 菜单战斗区下方，不插入原版技能槽。
- 控件原语 = Button + Image + Label。禁止构造 `SleekSkill`、禁止走 `sendUpgrade`、禁止写入 `Skill[][]`。
- 原版模板接入失败时走本票 Q5 的设置页降级面（现网表面 B），不是被动压弹票。

### Q2 — 名称沿用，描述与被动压弹对齐

技能页、设置页降级面和 Tooltip 共用同一描述事实源。名称：0 基础、1 快速换弹、2 自动压弹。花费仍 125 / 150。

- **0 基础**：可双击换弹键立刻压弹；有额外技能冷却。
- **1 快速换弹**：取消额外技能冷却；防重复提交的技术闸仍然保留。
- **2 自动压弹**：每 8 秒自动为身上五页中的空或未满弹匣，从匹配弹药箱填弹；仍可双击换弹键立刻手动压弹。

2 级不得再写成「双击后等待一轮」。不写枪上匣、超限、整理后合匣。

### Q3 — 设置根 + 原版三元组，不用显示名

- 账仍在现有设置根，不写进原版 `Skills.dat` / `Skill[][]`，不新建第三套持久化根。
- 键 = `serverID × characterID × 地图名`。三者必须共同组成身份，禁止只用 `serverID`。
- 单人：稳定的单人存档/槽位标识（现网 `Singleplayer_<Characters.selected>` 方向）。独服：服务器身份。`characterID` = 原版角色槽位 byte，不是显示名。地图名 = 原版当前地图身份。
- 同一世界不同角色独立计等级。客机只显示主机确认后的等级。沿用 LIT 熔断的「设置根 + map×slot 分文件」方向。

### Q4 — 旧全局账丢弃，每个世界从 0

- `better-inplace-reload.skill-levels.dat` 不迁移、不复制、不作为新世界初始等级。
- 每个世界/存档第一次进入从 0 级开始。禁止静默把全局满级抄进每一份新世界。
- 不增加一次性游戏内弹窗。玩家手册可写「换弹技能等级按世界、角色槽位分别保存」，归文案票。

### Q5 — 一处表面，一套账

- 战斗区成功挂载复刻行时只显示那一处。探测失败才在更好的换弹体验设置页显示同一套等级、描述和升级入口。
- 两表面不得同时显示；只共享同一等级账、同一主机授权、同一升级入口。
- U3DS 不画，也不因为没有画面而使用设置页替代。表面失败不能降级成另一套账或客户端自行升级。

### 本票不做

写入原版 `Skill[][]`；占一条原版战斗技能槽；新 FeatureId；超限三级按钮；造假职业图标/加成；本票改被动压弹间隔；迁移旧全局满级；第三套持久化根。

受影响：CONTEXT「换弹技能」补作用域三元组、复刻行零件、旧账丢弃、表面互斥。玩家手册归文案票。SDK 零改。
