## What to build

## Comments

### 2026-09-16 认领轮：必填参数落名 + 实施裁决（用户当场裁定数值；裁决为票内实施定界，不开新决策票）

**必填参数（票面冻结，测试只引用这些常量——对应规格「先例」条）**：

- `XP_COST_LEVEL_0_TO_1 = 125`（0→1 经验花费；用户裁定 2026-09-16）
- `XP_COST_LEVEL_1_TO_2 = 150`（1→2 经验花费；用户裁定 2026-09-16）
- `LEVEL0_EXTRA_COOLDOWN_SECONDS = 8`（0 级额外技能冷却秒数；用户裁定 2026-09-16）
- `AUTO_ROUND_DELAY_SECONDS = 8`（2 级自动压弹等待，沿用规格建议值，本阶段不可设）
- `MAX_SKILL_LEVEL = 2`（无三级；技术安全闸 `ReloadRuntimePolicy.CooldownSeconds = 1.5` 沿用现网不删不改）

**实施裁决**：

1. **冷却时序（Q3「最终可用时间=技术闸+额外冷却」）**：0 级的可双击窗口 = 技术闸 1.5s + 额外 8s = 合并 9.5s 单窗（`readyAt = 成交时刻 + 1.5 + extra(level)`）；窗内再双击 → 技能侧拒绝 = 红色剩余秒（主机为准，剩余含窗头技术段——那就是这条合并窗的真实剩余）。技术闸独立拒绝（≥1 级的纯技术刷屏、功能 A 合并路径）保持现网静默——技术闸触发不伪装成技能冷却。技能窗只由功能 B 双击成交开启；功能 A 合匣不吃技能窗、不开技能窗。
2. **升级权威**：主机校验（存储等级==目标-1 ∧ 目标≤2 ∧ `experience>=cost`）→ `askSpend` 扣原版经验（主机权威复制，插件自检余额——askSpend 无余额门）→ 按玩家/角色（steamId + characterName）持久化（自有文件，不写 `*.bue-settings` 设置文档、不写原版 `Skill[][]`）→ 客户端只显示主机确认等级。新档不送等级（默认 0）。经验不足=零扣零改。
3. **两种表面=两个 presentation adapter（规格实施纪律）**：表面 A=U 菜单战斗区下方分区（`PlayerDashboardSkillsUI.updateSelection` 恰一命中 binder 显式解析，postfix 注入，等级+升级按钮+无三级 UI 无占位）；表面 B=该功能设置页（**仅当注册期 binder 探测接不上**才挂 LIR settings facet：升级请求 Choice 行，写回即经功能私有频道向主机请求，主机校验后回执显示确认等级，行复位——不造第二事实源，等级事实恒在 LIR 存储）。两表面同时至多一。
4. **2 级自动压弹**：手动双击成交（Committed∧total>0）后固定等待 8s（不可设）→ 到点重检（等级仍≥2 ∧ 同枪同匣指纹 ∧ 玩家可解析），不满足即取消不强制；再压走同一权威入口（吃技术闸；2 级无额外技能窗）；自动轮成功不再触发自动轮（「双击成功后再自动压一轮」=每手动成功一轮）；手动再双击始终走手动路径。恢复路径仍不触发 A（04/05 现网语义，零改动）。
