# 确定模块化、兼容与故障隔离原则

Type: grilling
Status: resolved
Author: GPT
Blocked by: GPT-01, GPT-02

## Question

功能模块如何组织、发布和隔离故障，公共 API 如何演进？

## Answer

各功能使用独立工程并保持单向依赖，最终构建合并为一个 DLL。模块默认不能依赖其他模块内部实现。单个模块失败时应被禁用和隔离，后端记录明确错误与版本信息，前端显示功能启动失败提醒；核心及其他模块继续运行。只有共享契约或核心运行时损坏才阻止整个插件启动。公共 API 使用语义化版本，次版本保持向后兼容，破坏性变更只进入主版本，弃用接口至少保留一个次版本周期。
