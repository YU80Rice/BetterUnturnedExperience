## Answer

- 收藏=（种类, StableId）双键：`feature:`/`plugin:` 前缀桶；同串 id 两行各自亮星/摘星；单参重载=功能优先。
- 旧盘单键记录按「按种类分桶迁移」拆（票面第二方案）：首次 `Refresh` 目录就绪时归桶一次（碰撞=功能优先，否则贴插件行保住独有 GUID），改写成前缀键并持久化，此后不随注册/注销漂移——红测 `LegacyBareFavoriteBindsFeatureRowOnly` / `LegacyBareFavoriteForPluginOnlyGuidStaysOnPluginRow` 钉住两面。
- 「需要重启」顶栏徽章上移模型（`ShowsRestartBadge`），按最近一次尝试写入的 `(种类, StableId)` 点亮，NoChanges 不动（继承 Q67）；切到同 id 另一行不串台。行级（需要重启）标记天然只活在插件投影（F4 分工），红测补两面钉住。原生面板删本地徽章态，收藏按钮带种类。
- 全套 7/7 全绿、0 警告 0 错误；F4 回归组共存；契约仍 2.1；不授候选。
