# 原版语义只做公开解释，库存写入仍走原版权威提交

**Status: accepted**（V65-T1 关单，2026-09-21）

BUE 的公开原版语义 seam 只负责 Unturned 原版对象、状态、失败与代际的稳定解释（投影、绑定结果和失败语义）；官方业务写入仍经各自的原版权威提交路径——BII 拖入 `sendDragItem`/`takeItem`、LIT 整理 `removeItem`/`addItem`、LIR 压弹 `sendUpdateAmount`，三条互不替代。本阶段不合成统一写入权威，也不以共享解释 seam 取代既有原版提交责任。

理由：根因是「解释重复」，不是「写入入口数量不同」。把三条写入合成一条会制造第二个更大的权威迁移问题，并触碰玩法冻结（整理规则、换弹 0～2、拖入权威=ADR 0001）。写入不进契约同时守住「同权不等于同能力」：生态同权拿到的是同一个解释 interface 及其错误与生命周期语义，不是整理、压弹、拖入的业务能力。

## Considered options（否决原因不显然，记录）

- **合成统一公共写入权威**（否决）：改变玩法权威结构，超出「解释共享」目标，属治标。
- **公开 seam 带「请求提交」命令面**（否决）：等于把官方业务能力同权给生态，打穿同权≠同能力边界。
- **只读解释 seam + 写入留原版权威提交**（采纳）：与 BII 现行形态（ADR 0001：预览只读、提交走原版）一致，LIT/LIR 解释段可对称迁入。
